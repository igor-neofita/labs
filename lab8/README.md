# ЛР №8 — TypeScript, Webpack та REST API

## Реалізація

Застосунок використовує TypeScript, інтерфейси типів і репозиторій для роботи з REST API. Передбачено завантаження, додавання, редагування та видалення записів (GET, POST, PUT, DELETE). Інтерфейс побудований на HTML, SCSS та JavaScript, зібраному Webpack.

## Встановлення, перевірка та збірка

Потрібні Node.js і npm. Виконайте з каталогу `lab8`:

```bash
npm ci
npx tsc --noEmit
npm run build
node --check dist/bundle.js
```

Критерій успіху: усі чотири команди завершуються з кодом `0`. Зібраний файл має розташовуватися за шляхом `dist/bundle.js`; сторінка `index.html` завантажує саме його.

`dist/bundle.js` — результат збірки, а не місце для ручного редагування. Зміни треба вносити до TypeScript-файлів у `src/` і повторювати `npm run build`.
