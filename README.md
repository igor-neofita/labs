## Запуск і перевірка

ЛР №3–7 — статичні вебсторінки. Для коректної роботи API та модулів відкривайте їх через вебсервер або GitHub Pages, а не через `file://`.

Для ЛР №8 вихідний код розміщено в `lab8/src/`, зібраний застосунок — у `lab8/dist/bundle.js`. Перевірити збірку можна командами:

```bash
cd lab8
npm ci
npx tsc --noEmit
npm run build
node --check dist/bundle.js
```

`dist/bundle.js` генерує Webpack із TypeScript-джерел. Не змінюйте зібраний файл вручну: правки вносять у `src/`, після чого повторюють збірку.

**Стан на 03.11.2026:** у фінальному локальному комплекті зафіксовані успішні перевірки TypeScript і Webpack-збірки ЛР №8. Публікація GitHub Pages та повторна перевірка після змін мають підтверджуватися окремо.
